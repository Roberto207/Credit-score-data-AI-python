# Credit-score-data-AI-python
 README - Previsão de Score de Crédito com Machine Learning
🎯 Descrição
Sistema de Machine Learning para predição de score de crédito bancário, classificando clientes em categorias de risco (bom, médio, ruim). O projeto foca na preparação rigorosa de dados financeiros, engenharia de features e seleção do melhor modelo de IA para máxima acurácia preditiva.

🔧 Funcionalidades
Limpeza e pré-processamento de dados bancários (tratamento de missing values, outliers e inconsistências)
Engenharia de features para otimizar variáveis preditoras de comportamento de crédito
Pipeline de deploy para predições em novos dados de clientes

🛠️ Tecnologias
Python 3.10+
Pandas & NumPy - Manipulação e análise de dados
Scikit-learn - Modelos de ML e validação cruzada
Matplotlib & Seaborn - Visualização de dados e resultados
Jupyter Notebook - Desenvolvimento iterativo e documentado

📊 Dataset
Dados bancários anonimizados de clientes com histórico de crédito
Features: renda, histórico de pagamentos, dívidas existentes, tempo de relacionamento, etc.
